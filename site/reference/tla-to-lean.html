TLA+ ↔ Lean 4 Rosetta Stone

Already think in Lamport's state machines, invariants, TLC model checking, and refinement mappings? Filter every TLA+ construct alongside its idiomatic zero-dependency Lean 4 counterpart.

State Variables (`VARIABLES`)

TLA+ declares untyped global variables; Lean groups state cleanly into a typed `structure`.

TLA+ / PlusCal Idiom 
VARIABLES leaderEpoch, storageEpoch, committedVal
Lean 4.36.0 Idiom 
structure SysState where
  leaderEpoch  : Nat
  storageEpoch : Nat
  committedVal : Option String

Initial State Predicate (`Init`)

Express deterministic initialization as a value `init : S` or nondeterministic initial sets as `Init : S → Prop`.

TLA+ / PlusCal Idiom 
Init ==
  /\ leaderEpoch = 1
  /\ storageEpoch = 1
  /\ committedVal = "none"
Lean 4.36.0 Idiom 
def Init (s : SysState) : Prop :=
  s.leaderEpoch = 1 ∧
  s.storageEpoch = 1 ∧
  s.committedVal = none

Next-State Relation (`Next`) & `UNCHANGED`

Record update syntax `{ s with field := v }` automatically keeps all unmentioned fields `UNCHANGED` without forgetting any!

TLA+ / PlusCal Idiom 
BumpEpoch ==
  /\ leaderEpoch' = leaderEpoch + 1
  /\ UNCHANGED <<storageEpoch, committedVal>>

Next == BumpEpoch \/ CommitWrite
Lean 4.36.0 Idiom 
inductive Next : SysState → SysState → Prop
  | bumpEpoch (s : SysState) :
      Next s { s with leaderEpoch := s.leaderEpoch + 1 }
  | commitWrite (s : SysState) (v : String)
      (h : s.leaderEpoch ≥ s.storageEpoch) :
      Next s { s with storageEpoch := s.leaderEpoch, committedVal := some v }

Refinement Mapping & Stuttering (`INSTANCE Abs WITH ...`)

Concrete implementation steps map either to an abstract `SpecNext` step or an abstract stuttering step `abs s' = abs s`.

TLA+ / PlusCal Idiom 
Abs == INSTANCE SpecKV
  WITH kv <- [k \in Keys |-> LookupLog(log, k)]

THEOREM ImplSpec => Abs!Spec
Lean 4.36.0 Idiom 
def abs (impl : ImplKV) : SpecKV := lookupLog impl.log

theorem compact_stutters (impl : ImplKV) :
    abs (compact impl) = abs impl := ...

Bounded Progress / Termination (`WF_vars` / Variant Function)
